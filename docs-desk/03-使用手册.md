# dsh 官方桌面版 · 使用手册

> 面向使用者与二开验证者。基线 v0.1.6-alpha.2。

## 1. 三种运行形态

| 形态 | 命令/来源 | 数据目录 |
|---|---|---|
| 开发模式 | 仓库根 `pnpm run dev:desktop` | 本机：`D:\CursorWP\dsh\.dsh`（全局 DSH_HOME 指向）；未设 DSH_HOME 时才是 `.desktop-build/development/home/` |
| 可运行目录 | `pnpm run package:desktop:win:x64:dir` | 同上（DSH_HOME 或 `~/.dsh`） |
| 安装包 | `pnpm run package:desktop:win:x64:unsigned` 产出 NSIS 安装器 | 同上 |

## 2. 首次启动

1. dev 模式启动后会自动打开窗口（DevTools 也默认打开，正式感可设 `DSH_DESKTOP_OPEN_DEVTOOLS=0`）
2. 本机已配好模型服务商机（来自旧工作区 home，全局 `DSH_HOME=D:\CursorWP\dsh\.dsh`）：
   - **opencode-go**（默认，模型 glm-5.1，另有 glm-5.2、kimi-k3、deepseek-v4-pro、minimax-m3 等 17 个模型）
   - minimax-cn / kimi-coding / zai-coding-cn
3. 切换默认模型：会话内模型选择器或改 `home/settings.yaml` 的 `agent-default-model`

## 3. 核心功能（v0.1.6 桌面/Web 一体）

- **会话**：会话列表、聊天、工具调用可视化、审批/提问交互、归档会话恢复（v0.1.6）
- **多智能体**：Subagent 会话侧边栏（v0.1.6）、子代理模型选择（v0.1.2）
- **侧边栏**：终端（多标签，v0.1.6-alpha.1）、文件预览（Markdown/代码/HTML/PDF/图片，v0.1.5；Office 文件 v0.1.6）、浏览器模式（v0.1.6）
- **回合产物**：回合结束文件改动卡片与逐文件对比（v0.1.6）、模型显式交付文件（v0.1.5）
- **插件**：插件管理页——安装/配置/实时开关（v0.1.6）；插件走 Web 端共享插件管理器
- **Office 技能**：内置 office-docx/pptx/xlsx（依赖随应用分发的 Python 运行时，首次使用时离线安装）
- **实验性**：Browser Use / Computer Use / Auto review、SSH 远端工作区、MCP 资源发现

## 4. 数据与隐私

- 一切数据留在本机：`~/.dsh`（或 dev 模式的 `.desktop-build/development/home`）
  - `settings.yaml` 配置；`.credentials.yaml` API Key；`sessions/` 会话；`profiles/desktop/` 桌面独占 profile；`dsh-runtimes/` 内置 Python
- 桌面与 CLI **共享**会话/设置/凭据，但插件激活与运行包相互隔离
- 更新检查仅查询版本号；更新需第二次确认才安装

## 5. 更新与故障恢复

- 自动更新：Nightly 通道，10 分钟起轮询；有新版本先提示，**再次确认**才安装；更新失败自动回滚
- 致命故障（如插件导致起不来）：自动弹**原生恢复对话框**，可一键"禁用第三方插件并重启"
- 端口占用（19387）：按提示退出其他 dsh Desktop 实例（应用有单实例锁）

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 启动白屏/报 fatal | 看 DevTools Console（dev 默认开）；或删 `.desktop-build/development/home` 重来（dev 模式数据可丢弃） |
| 模型调用 401/无 Key | 检查 home 下 `.credentials.yaml` 对应 provider 的 Key |
| 改了壳代码不生效 | `dev:desktop` 是"一次构建+启动"，非 watch；改完重跑，或 `start:desktop` 复用产物前先 `build:desktop` |
| 与 CLI 同时使用 | 可以，数据共享但 profile 隔离；CLI 不能动 `profiles/desktop` |
| 想彻底重置 | 删 DSH_HOME（本机 `D:\CursorWP\dsh\.dsh`）下的 `profiles/desktop/`；未设 DSH_HOME 的 dev 则删 `.desktop-build/development/` |
